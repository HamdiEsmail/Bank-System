# Bank System 🏦

A console-based banking system built with C++ using procedural programming.

This was my second project at the beginning of my C++ learning journey.
The project was built to practice C++ fundamentals, problem-solving,
file handling, vectors, functions, and user permissions.

## 🚀 Features

### 👤 Client Management

- Add new clients
- Delete clients
- Update client information
- Find clients
- Display all clients
- Manage client accounts

### 💰 Transactions

- Deposit money
- Withdraw money
- Check total balance
- Prevent withdrawals that exceed the available balance

### 🔐 Authentication & Permissions

- User login system
- Username and password authentication
- User permissions system
- Assign specific permissions to users
- Access denied handling

### 👥 User Management

- List users
- Add new users
- Delete users
- Update users
- Find users
- Manage user permissions

### 💾 File Handling

- Store client data in files
- Store user data in files
- Read and write data using file streams
- Convert records between strings and structures
